# Открытые источники: загрузка и пробные предсказания

Два скрипта загружают четыре публичных набора и запускают пять отдельных
экспериментов. Архивы и исходные данные остаются в игнорируемой Git папке
`ml/external_datasets/`. Сохранённые модели VENA не переобучаются и не заменяются.

## Запуск

Из корня Vena, Python 3.12:

```bash
UV_CACHE_DIR=/private/tmp/vena-uv-cache uv venv ml/.venv --python 3.12
UV_CACHE_DIR=/private/tmp/vena-uv-cache uv pip install --python ml/.venv/bin/python -r ml/validation/requirements.txt

ml/.venv/bin/python ml/open_sources/download.py
MPLCONFIGDIR=/private/tmp/vena-matplotlib OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  ml/.venv/bin/python ml/run_open_source_experiments.py
```

Если окружение уже настроено, достаточно двух последних команд. Для скачивания
нужен доступ к UCI, Zenodo и NIST. Ключи API не требуются.

Загрузка отдельных источников:

```bash
ml/.venv/bin/python ml/open_sources/download.py --datasets hydraulic water nist_smoke
```

По умолчанию скачанные файлы переиспользуются с проверкой SHA-256; для Zenodo
также сверяется опубликованный MD5. Для ZIP проверяется CRC, запрещены пути
вне папки распаковки и symlink, задан лимит распакованного объёма. Частичные
скачивания пишутся в `.part`; окончательный файл заменяется только после проверки.
`--force` повторно скачивает выбранные источники. Повторная загрузка означает
возможную смену версии данных — сравнивайте сохранённые manifest.

Пути можно изменить:

```bash
ml/.venv/bin/python ml/open_sources/download.py --root /path/to/data
MPLCONFIGDIR=/private/tmp/vena-matplotlib OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  ml/.venv/bin/python ml/run_open_source_experiments.py \
  --data-root /path/to/data --output ml/results/my_open_source_run
```

Для нового эксперимента задавайте новую папку `--output`. Стандартная папка
этого исследования — `ml/results/open_sources_2026-10-20/`.

## Источники и задачи

| Набор | Доступ и происхождение | Эксперимент |
|---|---|---|
| MetroPT-3 | [UCI](https://archive.ics.uci.edu/dataset/791/metropt+3+dataset), Davari et al., DOI 10.24432/C5VW3R, CC BY 4.0 | Сохранённые pump_24h/72h через событийный адаптер; отдельно Isolation Forest на аналоговых измерениях |
| Hydraulic | [UCI](https://archive.ics.uci.edu/dataset/447), Helwig et al., DOI 10.24432/C5CW21, CC BY 4.0 | Классификация степени текущей утечки насоса по завершённому циклу |
| Urban Water | [Zenodo](https://zenodo.org/records/15096167), Babela et al., DOI 10.5281/zenodo.15096167, CC BY 4.0 по README | Классификация ±7-дневной близости к утечке по готовым anomaly scores |
| NIST Smoke | [NIST TN 1947](https://www.nist.gov/el/fire/engineered-fire-safety/data-smoke-alarm-performance), публичные экспериментальные данные NIST | Предсказание первой тревоги за 10 секунд на smoke-box экспериментах |

Три диагностических классификатора — HistGradientBoosting с фиксированными
параметрами. Это новые экспериментальные модели, а не проверка существующей
VENA на несовместимых признаках. Артефакты сохраняются рядом с отчётом с
суффиксом `_diagnostic.joblib`; используются только локальные доверенные
артефакты, произвольные скачанные pickle/joblib не загружаются.

## Протокол

- **MetroPT/VENA:** прежний фиксированный адаптер событий, отдельная разметка
  четырёх отказов из UCI, сохранённые пороги high. Четыре отказа одного агрегата
  не являются четырьмя независимыми объектами.
- **MetroPT/analog:** Isolation Forest обучается на феврале, без меток отказов.
  Признаки — средние за последний час и среднее/std за последние шесть часов.
  Порог — 99-й процентиль только обучающих anomaly scores. Тест апрель–июль.
  Ресемплинг закрыт справа и помечен временем конца окна; будущие значения не
  используются. Пропущенная история приводит к пропуску прогноза, а не к
  заполнению из будущего. Итоговая сравнительная таблица использует пересечение
  временных точек VENA и analog. Бюджеты тревог различаются и показываются явно.
- **Hydraulic:** 25% групп `cooler/valve/accumulator` отложены целиком, seed=42.
  Эти поля используются только для разбиения; целевая степень утечки и
  остальные метки из profile.txt не входят в признаки. Вход — mean/std/min/max/
  изменение за цикл для 14 физических датчиков. Прогноз доступен после цикла.
  Это один стенд, не доказательство переноса на другой насос.
- **Water:** обучение до 17.09.2022, тест с 01.10.2022, 14 суток между ними.
  Пропуски обрабатываются моделью; полностью пустые в обучении признаки
  исключаются. Порог 0.5. Положительная метка включает время ПОСЛЕ утечки.
  Причинность предварительно рассчитанных признаков неизвестна. Результат
  нельзя интерпретировать как качество раннего предупреждения.
- **NIST:** 25% моделей извещателей целиком отложены, seed=42. Из каждого
  эксперимента берутся точки каждые 5 секунд до первой тревоги; цель —
  наступление тревоги в `(t, t+10s]`. Вход — затемнение, MIC и CO, их прошлые
  средние/std за 10 секунд. Alarm?, Microphone, идентификатор и время до тревоги
  исключены из входов. Порог 0.5 не подбирается по тесту. Первые 10 секунд с
  артефактом фильтра исключены. Room-файлы загружены, но без явных onset-меток
  не используются: требуется сопоставление с отдельной таблицей результатов.

Все метрики — результаты одного фиксированного разведочного протокола.
Объединять их в «общую точность VENA» нельзя: задачи, горизонты и базовые частоты
различаются. Окончания отказов MetroPT взяты из отчётов как есть; точное время
возврата в работу отдельно не подтверждено.

## Результаты и контроль

- `REPORT.md`: сравнение и вывод о пригодности каждого набора.
- `report.json`: метрики, параметры разбиений, тестовые группы, исключения.
- `protocol.json`: параметры и хеши исходного кода/production-артефактов до запуска.
- `sources.json`: URL, атрибуция, размеры, SHA-256 архивов и распакованных файлов.
- `*_predictions.csv[.gz]`: предсказания на отложенных данных.
- `*_diagnostic.joblib`: отдельные модели и порядок входных признаков.

Перед экспериментом повторно проверяются хеши входных файлов, после — неизменность
production-моделей. Отчёт по каждому завершённому источнику записывается сразу.
Проверки без сети:

```bash
cd ml
MPLCONFIGDIR=/private/tmp/vena-matplotlib OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  .venv/bin/python -m pytest open_sources/test_open_sources.py validation/test_validation.py -q
```

Работа изолирована в новых файлах: существующие конфликты слияния в репозитории
этот конвейер не разрешает.
