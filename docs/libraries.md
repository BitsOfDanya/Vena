# Библиотеки и компоненты

Точные версии зафиксированы в `backend/uv.lock`, `frontend/pnpm-lock.yaml`, `ml/requirements.txt`.

## Инфраструктура

| Компонент | Версия | Назначение |
|---|---|---|
| PostgreSQL | 16 (поддерживается 12+) | хранение оперативных данных и истории |
| Docker Compose | v2 | запуск db, backend, frontend |
| Node.js | 22 | среда выполнения интерфейса |
| Python | 3.12 | backend и ML |
